# Locate first-time visitors with a Netlify Edge Function

When a first-time visitor doesn't arrive on a **Resort**'s page, their **Starter resort** is the one nearest to them instead of a random one. Their location comes from a small Netlify Edge Function that returns the IP geolocation Netlify already attaches to every request. A third-party IP lookup would send every visitor's IP address to another company and is often blocked by ad blockers. The browser timezone is too coarse: one zone such as `America/Los_Angeles` spans Seattle to San Diego. Browser geolocation would open a permission prompt before the visitor has seen anything.

This is the first server-side code since ADR 0001 removed the backend, and it does not reverse that ADR. The function is stateless and never calls Open-Meteo, so forecasts are still fetched in the browser under each visitor's own **Rate limit**. It does tie the site to Netlify: moving to another host means finding that host's equivalent of request geolocation.
